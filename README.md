# BB-EletroRota
Plataforma de Localização e Planejamento de carregamento para Carros Elétricos

## Necessario para rodar o sistema:



Paleta de cores:

Amarelo: #ffdf00
Amarelo: #efd731 
Azul: #003a8f
Azul claro: #1a73e8
Azul para nomes: #2116b8

O sistema utiliza o Json-server para simular o banco de dados,para cadastrar
usuarios e fazer login baseado nos usuarios ja cadastrados.
